# DawAudioStreamer 0.4.0-beta.2

初めて使う人向けの案内を分かりやすくしたベータ版です。

## 変更点

- READMEとReleaseの説明を短く整理
- Discord用のVB-CABLE案内をREADME冒頭とVST画面に表示
- VB-CABLEがない場合、インストール完了後に公式ページを開く設定を既定でオンに変更

OBSだけで使う場合、追加ソフトは不要です。Discordにも音を載せる場合はVB-CABLEを導入してください。

## 使い方

1. インストーラーを実行します。
2. DAWのマスターバスの最後へ「DAS Send」を1個挿します。
3. OBSでは「DAS Audio（DAW）」を追加します。
4. DiscordではDAWアプリまたは画面全体を共有します。

インストーラーは未署名です。Windowsが警告を表示する場合があります。
