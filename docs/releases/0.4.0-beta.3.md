# DawAudioStreamer 0.4.0-beta.3

公開者名とGitHub URLを現在の`yoruhinot`へ統一したベータ版です。
音声処理や使い方はbeta2から変わりません。

## 対応環境

- Windows 11 x64
- VST3対応の64-bit DAW
- OBS Studio x64
- Discordデスクトップ版

Studio One Pro 8、REAPER、Cubaseで動作を確認しています。

## 使い方

1. インストーラーを実行します。
2. DAWのマスターバスの最後へ「DAS Send」を1個挿します。
3. OBSでは「DAS Audio（DAW）」を追加します。
4. DiscordではDAWアプリまたは画面全体を共有します。

Discordにも音を載せる場合はVB-CABLEが必要です。インストーラーは未署名のため、Windowsが
警告を表示する場合があります。
