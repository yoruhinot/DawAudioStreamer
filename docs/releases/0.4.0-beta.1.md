# DawAudioStreamer 0.4.0-beta.1

DawAudioStreamerの初回公開ベータ版です。オーディオインターフェースのASIOを使うDAWへ
「DAS Send」を1個挿すと、DAWの出力設定やDiscordのマイクを変えずにOBSとDiscord画面共有へ
マスター音声のコピーを送れます。

## ダウンロード

- `DawAudioStreamer-Setup-0.4.0-beta.1.exe`：Windows x64用インストーラー
- `DawAudioStreamer-0.4.0-beta.1-source.zip`：配布バイナリに対応する完全なソース

両ファイルはGitHub ReleaseのAssetsから入手してください。公開時に記載するSHA-256と一致しない
ファイルは実行しないでください。

## 最短手順

1. OBS、Discord、DAWを終了してインストーラーを実行します。
2. DAWのマスターバスの最後へ「DAS Send」を1個挿します。
3. OBSでは「DAS Audio（DAW）」をソースへ追加します。
4. DiscordではDAWアプリまたは画面全体をそのまま共有します。

Discord用の無音仮想出力がない場合、セットアップが案内します。第三者ドライバーは同梱せず、
Windowsの既定音声出力やDiscordのマイク設定も変更しません。

## 確認環境

- Windows 11 x64
- Studio One Pro 8
- OBS Studio x64
- Discordデスクトップ版

OBS録画とDiscord視聴側の音声を実機確認済みです。

## ベータ版の注意

- インストーラーとバイナリは未署名です。Windowsが発行元不明またはSmartScreenの警告を表示する
  場合があります。
- 長時間配信、すべてのDAW、オーディオインターフェース、サンプルレート、バッファサイズでの確認は
  完了していません。本番前に短い限定配信で確認してください。
- Discordの画面共有音声はDiscordおよびWindows側の挙動変更の影響を受ける可能性があります。
