# DawAudioStreamer 0.4.0-beta.1

初回ベータ版です。

DAWのマスターバスへ「DAS Send」を挿すと、ASIO設定を変えずにOBSとDiscord画面共有へ
音声を送れます。Discordのマイク設定も変更しません。

## 使い方

1. インストーラーを実行します。
2. DAWのマスターバスの最後へ「DAS Send」を1個挿します。
3. OBSでは「DAS Audio（DAW）」を追加します。
4. DiscordではDAWアプリまたは画面全体を共有します。

OBSだけで使う場合、追加ソフトは不要です。Discordにも音を載せる場合はVB-CABLEが必要です。
入っていないPCではインストール完了時に公式ページが開きます。

Windows 11 x64、Studio One Pro 8で動作を確認しています。

## 注意

インストーラーは未署名です。Windowsが警告を表示する場合があります。実際の配信前に短い録画や
限定配信で動作を確認してください。

詳しい手順は[README](../../README.md)、不具合や要望は
[Issues](https://github.com/SecondLunchi/DawAudioStreamer/issues)を参照してください。
