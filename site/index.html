SETUP

セットアップ

ダウンロードしたOSの案内を、上から順番に進めてください。

WINDOWS 11

Windowsで使う

最初の2手順はOBSとDiscordで共通です。

  1. 1
    DASをインストール

    OBS、Discord、DAWを終了してから、ダウンロードしたインストーラーを実行します。

  2. 2
    DAWのマスターに挿す

    マスターバスの一番最後に、VST3プラグイン「DAS Send」を1個追加します。

DAWごとの場所

名前は違っても、最終的な音が通る場所の最後に挿します。

Studio One Pro 8動作確認済み

コンソールの「メイン」チャンネルにある、インサートの最後へ追加します。

Cubase動作確認済み

MixConsoleの「Stereo Out」にある、Insertsの最後へ追加します。

REAPER動作確認済み

MASTERトラックの［FX］を開き、エフェクト列の最後へ追加します。

3

配信先を選ぶ

OBSとDiscordは別の手順です。使いたい側だけ進めます。

OBS

配信・録画に使う

DAWの音をOBSの音声ミキサーへ直接送ります。

  1. 1OBSの「ソース」で［＋］を押す
  2. 2「DAS Audio（DAW）」を追加
  3. 3DAWを再生してメーターを確認

VB-CABLEは不要です

DISCORD

画面共有に音を載せる

WindowsではVB-CABLEを、DAS内部の音声経路として使用します。

先にVB-CABLEをインストール
  1. 1公式ZIPを展開
  2. 2「VBCABLE_Setup_x64.exe」を管理者として実行
  3. 3［Install Driver］を押してWindowsを再起動
VB-CABLE公式サイト ↗
  1. 4DAS Sendが「準備完了」になることを確認
  2. 5DiscordでDAWまたは画面全体を共有
設定は変えません

「CABLE Input」をDAWの出力やDiscordのマイクに選ばないでください。DASが内部で使用します。

共有する音だけを選びたい場合

「配信用BUS」を1本作り、配信したいトラックだけを送ります。そのBUSの最後にDAS Sendを1個挿すと、自分だけが聞く音を配信から外せます。

macOS PREVIEW

Macで使う

Apple Silicon搭載Mac・macOS 13以降向けです。

  1. 1
    ZIPを展開

    DAWとOBSを終了してから、ダウンロードしたZIPを展開します。

  2. 2
    インストール

    「Install.command」をControlキーを押しながらクリックし、［開く］を選びます。

  3. 3
    DAWとOBSに追加

    DAWのマスターへ「DAS Send」、OBSのソースへ「DAS Audio（DAW）」を追加します。

OBS
DASを使います

DAWを再生し、OBSの音声ミキサーが動けば準備完了です。

Discord
DASは通常不要です

DAWアプリまたは画面全体を共有すれば、macOS標準機能で音声も共有できます。

プレビュー版です

Appleの正式な署名・公証前のため、macOSが警告を表示します。

TROUBLESHOOTING

うまくいかないとき

該当する項目だけ開いて確認してください。

DAS SendがDAWに出てこない

DAWのVST3またはAUプラグインを再スキャンします。インストール後にDAWを再起動していない場合は、一度終了して開き直してください。

OBSにDAS Audioが出てこない

OBSを完全に終了して開き直します。その後、「ソース」の［＋］をもう一度確認してください。

Windows版のDiscordがVB-CABLEのまま

VB-CABLEの64-bit版を管理者として導入し、Windowsを再起動してください。

音が二重に聞こえる

OBSでDAS Audioとデスクトップ音声の両方から、同じDAW音声を取り込んでいないか確認します。DAS Sendも1個だけにしてください。

アンインストールしたい

Windowsは「インストールされているアプリ」から削除します。MacはDAWとOBSを終了して「Uninstall.command」を実行します。

それでも解決しない

GitHub Issuesで使用OS、DAW、OBSのバージョンと症状を知らせてください。
