SETUP

Setup

Only the install step differs by OS. Everything after that is the same.

1

Install for your OS

This is the only step that differs by OS.

Windows 11

Run the installer

Close OBS, Discord, and your DAW, then run the downloaded installer.

macOS 13+

Open Setup

Extract the ZIP and close your DAW and OBS. Open “DawAudioStreamer Setup.app”, click Install / Update and wait for completion.

Can't open or install? · Older ZIPs use “Install.command”.
2

Insert in your DAW's master

Same for Windows and macOS from here. Add one DAS Send instance at the end of the chain where your final audio passes through.

Where to insert by DAW

Windows uses VST3; macOS uses AU or VST3.

Fender Studio Pro 8verified

Add it at the end of the inserts on the Main channel in the Console.

Cubaseverified

Add it at the end of Inserts on the Stereo Out channel in MixConsole.

REAPERverified

Open FX on the MASTER track and add it at the end of the effects chain.

Ableton Live 12verified

Add it at the end of the Audio Effects chain on the Master track.

DISCORD
Windows

Send to Discord screen share

On Windows, DAS uses VB-CABLE as its internal audio route.

Not needed on macOS

Sharing your DAW app or full screen uses macOS built-in audio sharing — no extra setup required.

Install VB-CABLE first
  1. 1Extract the official ZIP
  2. 2Run "VBCABLE_Setup_x64.exe" as administrator
  3. 3Click Install Driver and restart Windows
VB-CABLE official site ↗
  1. 4Check the Discord indicator in DAS Send shows a green OK
  2. 5Share your DAW or full screen in Discord and ask a viewer to check the audio
Don't touch these settings

Do not set "CABLE Input" as your DAW output or Discord microphone. DAS uses it internally.

Want to choose exactly what audio goes to the stream?

Create a dedicated "stream bus", route only the tracks you want to stream into it, and insert one DAS Send at the end of that bus. This lets you keep some audio private — heard only by you, not the stream.

TROUBLESHOOTING

Troubleshooting

Open only the item that applies to you.

Can't open or install Setup on Mac

After trying to open it, go to System Settings → Privacy & Security → Open Anyway → Open. Only do this for your trusted official download. Do not bypass malware or damaged-app warnings; contact support instead. Apple's guide

For write-access errors, use Show in Finder, then Get Info → Sharing & Permissions on the affected folder. Ask your Mac's administrator if you cannot change access. Setup does not change permissions.

For missing files, download and fully extract the ZIP again. If recovery files remain, do not delete them; use Copy details and contact support. Wait for “Installation complete” before continuing to your DAW and OBS.

Older Install.command versions ask for a language: press Enter to use the default. Terminal's “Process completed” does not mean installation succeeded. Look for the script's own installation-complete message.

OBS says “No properties available”

Older versions show this because the source needs no settings. It is normal. Close the dialog, insert one DAS Send on your DAW master, then play audio and check the OBS audio mixer or a recording.

DAS Send doesn't appear in my DAW

Rescan VST3 or AU plugins in your DAW. If you haven't restarted your DAW since installing, close and reopen it.

DAS Audio doesn't appear in OBS

Fully close and reopen OBS, then check + under Sources again.

Older OBS versions may not show DAS Audio. If it's missing, update OBS to the latest version and try again.

Discord on Windows is stuck on VB-CABLE

Install the x64 version of VB-CABLE as administrator and restart Windows.

I hear doubled audio

Check that you're not capturing the same DAW audio through both DAS Audio and Desktop Audio in OBS. Also make sure there's only one DAS Send instance.

I want to uninstall

On Windows, remove it from Installed apps in Windows Settings. On macOS, close your DAW and OBS, choose Uninstall in Setup.app and wait for completion. DAW projects and OBS scenes are kept. Older ZIPs use “Uninstall.command”.

Still not working

For bugs or requests, reach out on X (@yoruhinot) or GitHub Issues. Include your OS, DAW, and OBS version along with a description of the problem.
